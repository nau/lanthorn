- GAP: The spec does not say whether non-lovelace assets in the deposit must go back to the guest. GEN-8 says to ignore them, so a host can Release or Claim the deposit and keep the tokens. | CHOSE: No token check on any action, as GEN-8 requires. Reported in the security review as a spec-level finding, left open.
- GAP: The spec does not say whether the staking part of the address of the guest or host output must match the booking. "Paid to X" ignores it, so the host can pay the guest's payment key under a different stake credential. | CHOSE: Ignore the staking part, as section 2 requires.
- GAP: The spec does not say whether outputs to the guest or host that carry a datum or a reference script count as paid. | CHOSE: They count, by payment credential alone, like any other output.
- GAP: The spec does not say how to round a negative product in the fee formula, where feeBps is negative. | CHOSE: divCeil on the signed product. The result is always raised to MIN_FEE, so the rounding direction has no effect.
